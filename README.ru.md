# Claude Code Status Limits

Скрипт статус-бара для [Claude Code](https://claude.ai/code), который в реальном времени отображает заполненность контекстного окна и потребление rate-limit квот.

[English version](README.md)

## Что отображается

### Бар контекста

Показывает, насколько заполнено контекстное окно текущего разговора. При заполнении Claude Code автоматически запускает компрессию истории, чтобы освободить место.

### Бары rate-limit

Каждый бар отражает потребление квоты в рамках фиксированного временного окна — 5 часов или 7 дней. Название квоты и текущий процент отображаются текстом прямо внутри бара.

#### Как читать цвета

Каждый rate-limit бар одновременно кодирует два показателя: сколько квоты уже потрачено и как далеко продвинулось время внутри окна. Цвет показывает, что опережает — потребление или время:

**Яркий зелёный** — потребление и время идут вровень, всё в норме.

**Тёмно-зелёный** — время уходит быстрее, чем тратится квота. Вы расходуете лимит экономно и запас ещё есть.

**Янтарный** — квота тратится быстрее, чем проходит время. При таком темпе вы, вероятно, упрётесь в ограничение до сброса окна.

**Тёмно-серый** — данных ещё нет, или окно только что открылось.

## Источники данных

Скрипт получает данные из двух независимых источников.

**Сам Claude Code** передаёт заполненность контекста и состояние 5h/7d лимитов после каждого хода. Эти значения появляются только после начала разговора, поэтому самый первый рендер нового чата использует закешированные данные из предыдущей сессии.

**Usage API claude.ai** предоставляет квоты по отдельным моделям — Sonnet 7d, Opus 7d и другие. Запросы выполняются с использованием OAuth-токена самого агента, поэтому отдельных учётных данных не требуется. Данные обновляются не чаще одного раза в 5 минут.

## Кеширование

Последнее известное состояние каждого бара сохраняется в `~/.claude/status_limits_cache.json`. Благодаря этому бары всегда показывают что-то осмысленное даже в начале нового чата, до прихода первых данных. По мере поступления новых данных — от Claude Code или от API — кеш обновляется; при пересечении источников приоритет отдаётся живым данным от Claude Code.

## Установка

Добавьте в `~/.claude/settings.json`:

```json
"statusLine": {
  "type": "command",
  "command": "python /path/to/claude-code-status-limits/status_limits.py"
}
```

Укажите путь к директории, куда клонирован репозиторий. Требуются Python 3.10+ и `curl`.

### Ширина полоски баров

Claude Code размещает справа от вывода скрипта другие элементы (например, счётчик токенов), поэтому бары никогда не занимают всю ширину консоли. По умолчанию скрипт рендерится в 120 колонок. Чтобы задать желаемую ширину полоски, передайте её аргументом:

```json
"command": "python /path/to/claude-code-status-limits/status_limits.py 100"
```

Подберите значение так, чтобы бары заняли доступное пространство в вашем терминале.
